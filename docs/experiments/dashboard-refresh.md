# 02. 대시보드 결과 자동 조회

**상태** · 측정 계획. 구현 시간, 복잡도, 런타임 결과는 미측정입니다.

## 동일 과제

공통 화면과 가짜 작업 API에서 대기·진행·완료를 표시합니다. 정상 갱신, 느린 응답, 연결 단절 후 복구, 숨김 탭 복귀, 다중 탭 시나리오에 같은 이벤트 일정을 사용합니다. 서버 결과 기록 시각과 브라우저 표시 시각을 같은 시간 기준으로 수집합니다.

| 후보 | 최초 통과 | 전체 통과 | 변경 복잡도 | 채택 가설 |
|---|---|---|---|---|
| 고정 주기 폴링 | 미측정 | 미측정 | 미측정 | 새 서버 기능 없이 조회 지연과 요청 예산을 모두 충족할 때 |
| 적응형 폴링 | 미측정 | 미측정 | 미측정 | 진행 중 빠른 갱신이 필요하고 유휴 구간의 요청 절감 효과가 클 때 |
| SSE | 미측정 | 미측정 | 미측정 | 결과 전달 지연 요구가 엄격하고 장기 연결 및 재연결 복구를 지원할 때 |

## 측정과 판정

- **구현 속도와 시간**은 공통 API와 UI가 준비된 뒤 후보 시작부터 첫 결과 표시 및 전체 시나리오 통과까지 각각 잽니다. 새로 작성한 시간, 환경 설정·대기, 재작업을 작업 기록에 분리합니다.
- **복잡도**는 폴링 간격 또는 재연결 정책을 바꿨을 때 프런트엔드·서버의 수정 파일, 정책 분기, 의존성, 인프라 설정 지점을 셉니다.
- **사용자 경험과 부하**는 결과 반영 p95, 요청·바이트/분, 동시 연결 수, 오류 복구 시간, 누락·중복을 기록합니다. 고정 폴링은 1·3·5초부터 비교합니다. 목표 지연과 요청 예산은 결과 해석 전에 정합니다.
- **폴링 역추적**은 이슈·PR·커밋에서 확인한 당시 제약을 먼저 기록합니다. 새 실험에서 안전하게 선택할 수 있는 주기, 완료 시 중단, 느린 요청의 중복 방지, 백오프, 탭 복귀 정책을 직접 검증합니다.

기준별 승자는 측정 뒤 채웁니다. 외부 프록시의 SSE 동작과 운영 환경의 API 비용은 각각 연결 증거를 확보해 기록합니다.
